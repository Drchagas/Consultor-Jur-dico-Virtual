# Matriz funcional — JARBAS Jurídico 6.0

| Área | Situação 6.0 | Observação |
|---|---|---|
| CRM / Leads | Ativo | Funil, origem, honorário estimado, próxima ação e conversão em cliente |
| Clientes | Ativo | Cadastro e dossiê com casos, financeiro e agenda |
| Processos | Ativo | Cadastro, risco, fatos, provas, estratégia e upload simultâneo |
| Autos / GED | Ativo | PDF, SHA-256, extração, indexação, central documental |
| Copiloto jurídico | Ativo | Pergunte aos Autos, Hard Truth, análise, linha do tempo, minutas |
| Agenda | Ativo | Tarefas, reuniões, audiências, diligências e prazos internos |
| Prazos processuais | Ativo manual | Monitoramento automático de tribunais depende de integração externa |
| Financeiro | Ativo | Receber, pagar, contratos, parcelas, baixas, caixa, categorias e indicadores |
| Timesheet | Ativo | Horas por usuário/processo e valor potencial |
| Relatórios | Ativo | Carteira, riscos, CRM, inadimplência, caixa e produtividade |
| Equipe | Ativo | Workspaces e papéis básicos |
| Auditoria | Ativo | Registro de ações relevantes |
| Multiempresa / SaaS | Ativo no núcleo | Isolamento lógico por workspace; produção deve adicionar RLS |
| Publicações automáticas | Integração futura | Requer provedor/robô/API |
| Bancos / boleto / Pix / NFSe | Integração futura | Requer PSP/banco/provedor fiscal |
| Calendário/e-mail/WhatsApp | Integração futura | Requer OAuth/APIs |
| Jurisprudência oficial online | Integração futura | Deve usar fontes oficiais e rastreabilidade |
| OCR em lote | Integração futura | Necessário para autos sem camada textual |
| Portal do cliente | Integração futura | Exige autenticação e política de compartilhamento |
